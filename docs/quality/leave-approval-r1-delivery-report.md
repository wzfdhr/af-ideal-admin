## 范围及环境

R1 支持组合配置发布、持久化草稿、两名主管串行审批、驳回/撤回、复制为新申请、工作台/消息/历史和服务端审计。范围限请假业务，未将整个框架或所有旧演示模块标为生产化。

环境为 macOS arm64 驱动的 Chromium、Linux arm64 Docker、Node 24.17.0/npm 11.13.0、PostgreSQL 16、Fastify 5.12.5。生产前端连接真实参考 API；多账号使用独立浏览器上下文，标签页隔离用同一有双租户成员关系的账号。真实集成每次建立独立临时数据库，避免运行 worker 干扰故障场景。

演示账号来自共享 demoIdentities：A/B 每租户员工、两位主管、管理员、审计员，另有跨租户员工。独立试点使用私有一次性配置和随机凭据，不复用公开演示口令。时区 Asia/Shanghai，半日单位计入周末，单次最多366天，不扣假期余额。

## 能力矩阵及限制

| 能力 | 本交付状态 |
| --- | --- |
| R1 请假业务及参考后端 | 已实现并完成阶段验证，候选包退出门禁进行中 |
