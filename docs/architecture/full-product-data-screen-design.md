# FP-028/029 真实大屏实施边界

来源为冻结全产品 FP-028/029、T-353/T-611 及能力地图的大屏画布、六类图表、地图点位、拖拽/缩放/层级/对齐/吸附、主题、三套业务模板与真实刷新要求。当前 `dataScreen` 直接调用内存 Mock，只有一套静态运营模板；没有真实领域表、发布版本或运行数据。本文是后续实现决策，不是完成记录。

## 数据与授权

采用独立大屏领域，复用已有报表执行器。每个来源固定本租户已发布 `reportDefinitionVersionId`；由服务端登记并解析当前来源状态、行权限、字段投影及日期窗。画布和发布快照只保存配置、引用与明确口径，不保存业务行、凭据、SQL、脚本、任意 URL 或可执行表达式。

每次预览/刷新使用当前观看者的 `report:query` 及实际来源权限。大屏读取/运行权不能代替报表、业务行或字段权限。已发布报表及应用来源停用、撤权、账户/租户失效立即限制下一次刷新；不借发布人的身份共享数据。授权失败时清除该来源旧结果，不继续展示失权数据。仅网络失败可保留明确标注为过期的既有授权结果。

复用 `queryReportingVersion` 的实际 `queriedAt`、`dataCutoffAt`、数量、按日趋势、状态分布及投影明细。数量和状态排行来自全部受权筛选集合的服务器聚合，不能从当前明细页累加或保留静态指标。表格及地图使用有界明细并明确显示截断/分页范围。地图仅使用批准字段显式绑定的真实经纬度，验证经度 -180..180、纬度 -90..90；没有地理字段时明确缺少绑定，不捏造位置。

每个来源设置闭合自然日期窗、报表时区及明确状态筛选。数据窗由服务器当前时间构造；来源返回实际截止时间和口径。初版指标使用既有 count，不将数量宣称为成交额、转化率或设备健康值。后续若引入金额/比率，须追加独立的受权聚合契约、分母/精度/状态口径及真实数据验证。

## 草稿、快照与命令

新增 definitions/releases/events，保存草稿 revision、不可变布局/主题/来源绑定快照和 hash，以及活动发布指针。创建、复制、保存、发布、切换历史版、启停和归档采用命令 key/版本、租户门禁与事务审计。保存草稿不改变正在运行的发布版；回滚仅切换历史发布指针，不修改历史内容。复制具有独立标识、草稿及发布版本。

闭合新 schema v1 使用 1920×1080 基准画布，最多 30 个 widget，最小尺寸 160×96，8px 移动/缩放吸附，以及有界位置、连续层级、来源 key、材料参数和主题。多选对齐保留各材料尺寸，中心对齐允许精确中心位置不落吸附网格。验证来源 key 唯一、widget ID 唯一、引用存在、边界/最小尺寸及材料参数；未来版本或未知键拒绝。历史 Mock schema 的 URL、开放 props 等不自动转成受信执行配置；无法安全映射时保留原稿并明确拒绝。

控件提供折线、柱状、饼图、排行、指标卡、滚动表格；能力地图中的地图点位使用单独闭合坐标绑定。告警滚动展示当前受权业务状态计数或本次刷新错误等明确事实，阈值为有限数字和登记状态，不执行表达式。没有告警事实显示空态。

画布支持实际选择、拖拽、边角缩放、层级、对齐和吸附；属性面板及键盘可完成同一修改，保存后重开一致。移动/缩放按基准画布坐标约束，不把 CSS 缩放误当作保存坐标。预览按容器尺寸计算缩放；全屏调用浏览器 Fullscreen API 并反馈拒绝/退出。滚动表格、告警有暂停控制并遵循减少动态效果偏好。

## 三套模板与使用路径

模板是可复制的布局和绑定配方，不是固定业务数字。目录至少提供运营、销售、设备三套配方，预览和切换实际生效，并使用真实来源绑定向导。

- 运营：授权业务流转数量、日趋势、审批状态分布/排行及明细。
- 设备：绑定真实设备领用应用发布版及报表，展示领用单量、趋势、状态和批准明细，不把审批状态冒充硬件实时健康。
- 销售：通过现有通用应用配置/发布/业务记录链路建立明确的销售订单表单和审批绑定，再绑定销售订单报表。展示真实订单量、审批分布、日趋势及批准字段；需要地图时提供实际录入的地理字段。不得将设备数据改标题冒充销售数据。

模板的品牌色、暗色/行业主题及布局在草稿和发布快照中保存。租户通用品牌持久化属于 FP-032；大屏当前主题配置仍须独立持久化并验证。三套配方包含完整布局，所有使用来源都有真实绑定，无权限/无来源时明确反馈。

## 刷新与验收

按来源进行有界轮询、取消和去重，不让同一慢请求堆积。租户、身份、草稿/发布版本或来源变更后丢弃旧响应。分别显示首次加载、刷新中、最后成功、截止时间、过期、空、错误和权限状态。页面隐藏时暂停无意义刷新，恢复后重新授权刷新。

独立验收包括：schema 非法/未来格式；发布快照/草稿隔离；复制、保存刷新/关闭重开、回滚；版本冲突/幂等/事务失败；当前行/字段及双租户负向；三模板新增真实业务后轮询变化；来源停用、断网、晚到响应与过期；1920/1280、键盘拖动/属性修改、真实全屏及滚动暂停；API/worker/数据库重启、迁移备份恢复和对应远端 CI。Mock 仅保留开发演示，不能支持上述真实实现结论。新环境全产品部署及正式交付仍按 FP-043..045 完成。
