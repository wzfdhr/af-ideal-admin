# 表单发布版本对比与绑定草稿读取

FP-012进行中。本增量实现同一应用内“发布版本→当前编辑草稿”及“发布版本→发布版本”的只读对比。比较真实持久化发布快照和实际设计器编辑状态；未保存状态明确标注，不能冒充已保存版本或发布。没有发布版本时明确空态。

比较共享契约先严格解析格式，未知未来版本和非法定义显式报错。按稳定字段uid对齐，展示新增、移除、控件/标签/顺序/必填/只读/选项/数据源引用/校验/联动变化；独立比较表单布局、计算规则、格式版本、数据源登记及发布时生成的来源快照。对象键序忽略，字段及选项数组顺序保留。对比不变更任何定义、活动版本、旧记录或权限。

读取沿用后端application:read/configure及数据源权限，不复制一套未经授权的历史查询。应用详情现有releases来自租户条件查询，绑定源定义读取仍经过来源权限检查。切换应用/租户或读取失败清除旧定义，不显示上一上下文版本。API最新响应优先，旧请求不能覆盖新上下文。

修复配置页只在前100条草稿中找绑定定义的问题：按应用记录中实际formDraftId/workflowDraftId读取具体草稿，分页目录用于用户选择，不决定已绑定应用能否重开。R1保留既有可选草稿路径并确保当前绑定草稿即使位于后续页也加载；不存在/无权限不自动选其他应用草稿。

无需新增迁移，定义比较组件与共享函数可单独回退；v1/v2发布快照不改写。验证覆盖对象键序、增删改/顺序、规则/快照、非法格式、保存重开、真实两次发布、当前草稿修改、跨租户/撤权、后续页绑定重开、在途记录保持原发布及已有R1回归。整个FP-012的完整格式迁移、全套键盘/分辨率、部署/恢复和回退仍须继续验收。

编辑中的规则尚未通过发布校验时，预览与对比各自给出明确错误，不丢弃设计器编辑状态；修正后立即恢复。版本对比选择与活动版本切换选择独立，比较旧版本不会自动启用旧版本。对比表格用可聚焦选择框、details/summary和原生表格行列表头；真实路径在1280视口验证。
