# FP-027 持久定时报表实施决策

来源为冻结 FP-027、已有 reportSchedules 日/周/月、角色/部门/租户接收范围和导出格式入口，以及真实导出 FP-026。原 Mock 没有执行器、真实下次时间、时区、版本、重试或收件授权；保持独立 Mock，真实模式使用新契约和真实事实。

## 固定规则和日历

- v1 规则固定已发布 report definitionVersionId、CSV/XLSX/PDF、明确 IANA 时区、HH:mm、frequency。每日一次；每周指定 ISO weekday 1–7；每月指定 dayOfMonth 1–31，无该日期的月份跳过，不静默改为月末。时区必须与固定报告版的查询时区一致，界面明确展示。
- DST 不存在的本地时刻跳过当天；重复时刻只取第一次 UTC instant，一次本地 slot 不重复执行。日历计算仅使用闭合数据与 Intl，不接受 cron、脚本、表达式或客户端 now/nextRunAt。
- 数据窗只提供 previous-period/current-period 两种闭合选择。前一日/前一自然周（周一至周日）/前一自然月；当前窗为 slot 当日、所在周一至 slot 当日、所在月一日至 slot 当日，均按规则时区的完整日期边界。查询时实际状态/字段/授权与数据截止时间来自实际执行；补跑不冒充过去时刻的历史快照。状态覆盖已登记全状态，关键词为空，排序 createdAt desc，不共享发起者私有关键词。

## 耐久版本、启停和补跑

- schedule 保存可治理草稿/控制 revision；每次创建/编辑形成不可变 rule version。独立 activation period 固定规则、原主体、启用起点、可空关闭时间及待处理 cursor，保持历史。启用从当前时刻严格下一个 slot 开始，不补停用期间未启用的日期。
- 编辑/停用在同一事务关闭旧 period；已经处于启用区间的到期 slot 仍按旧版本 materialize，关闭后将来的 slot 不产生。已创建运行/导出独立取消，不由停用擦除；界面说明停用不会删除历史或取消已到期计划。
- worker 按到期 cursor 有界推进，每个 period/slot 唯一运行事实与固定接收快照后才推进下一 cursor；每次有限批量，但长期停机不能无声跳过已启用区间。一个 slot 多次扫描/并发/重启只产生同一个运行，原版本不被新编辑替代。
- 运行/逐收件处理用 lease/fence、有限退避及失败/blocked/取消事实。无接收人、来源/原主体/字段失权、未知格式、扫描或文件失败均可查询；部分收件失败不能显示全体完成。人工重试保持原运行/接收身份，不借操作人的数据权，不覆盖已完成制品。

## 收件人、导出与告警

- 接收规则仅 tenant/真实 roleId/真实 departmentId，限定当前租户/启用成员及发起者当前成员范围，使用真实目录选择和数量预览，不接自由文本人员名。最大收件数有界；运行固定实际集合，之后的失效保留 skipped/blocked，不能删事实凑成功。
- 每个收件人使用发起者与收件人的当前记录权限交集；逐字段值需要两方字段/成员范围同时准入后才能参与输出、筛选或排序。收件者须当前 query/export list/download 资格；没有输出字段/权限的收件失败明确，不假造数据或借发起者宽权限共享全文件。
- 专属 recipient grant 将该导出与运行/收件人固定绑定，扩展导出元数据/下载读取；普通附件命名空间仍不准入。下载复验原主体、收件规则当前资格、报告来源和每个捕获行/字段。新规则/停用不删除既有 grant，但撤权、角色/部门退出、账户或来源停用立即限制下一次访问。
- file-ready 与失败告警复用真实站内通知/Outbox/实时事实，唯一效果键和事务审计。只有实际扫描完成才提示文件可用；失败告警仅给当前有权的原主体/治理人，不带业务内容、requestId/access=copy 或授权下载 URL。外部邮件保持不可用，除非后续已有配置与明确发送授权。

- 拆为纯日历、耐久调度/交集捕获与 grant、真实前端/通知三条实现，根负责共享契约/迁移协调/接线/全量检查。先验证日历 DST/月末/自然窗，再实际 PG 并发/原 key/故障/租约/关闭旧周期补跑/多收件权限/通知/恢复，以及真实下一分钟触发 UI 与真实文件；不以 run-success 种子或模拟响应替代。
