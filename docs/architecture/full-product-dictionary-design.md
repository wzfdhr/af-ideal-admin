# 真实字典与选项实施方案

FP-008包含租户自有字典和字典项，不把项目资料管理扩展为另一个业务平台。现有状态枚举由平台保留，不能用可编辑字典改变授权或业务状态机。字典类型创建后固定，租户内唯一且删除后不复用，避免已保存配置引用另一份定义。

新增 dictionaries/dictionary_items 独立持久表，父子引用带 tenant_id。元数据及整批选项更新共用父字典 revision；创建、修改、删除有幂等键、事务事实审计。删除为墓碑，保留历史。选项仅允许有界标签和 string/number/boolean 值，最多200项，拒绝重复值、未知键与非法类型；排序明确，停用项不进入运行时选项。停用或删除字典的运行读取明确报错，不伪装成功空态。

治理采用既有 system:dict:list/detail/create/update/delete，运行选项增加独立 system:dict:read。所有读取重新验证当前身份及租户授权。客户端缓存按租户上下文代次隔离并有时限；上下文切换、手动刷新或当前编辑成功会失效。未完成请求不得覆盖新代次缓存。缓存只辅助显示，提交值的有效性需由后续受控数据绑定在服务端检验。

真实页面继续 ProTable/ProForm/adminUi 模式，新增选项编辑、保存/重开和运行预览；错误保留本地输入，409要求重新读取，不自动覆盖另一人的更新。Mock保持独立开发模式，不能当作持久化证据。引用保护、发布快照中的字典绑定以及跨进程缓存刷新由FP-011/012继续实现，不能把字典CRUD视为这些任务完成。

迁移013不改变既有字典Mock或R1数据；实际应用前先在独立数据库验证。回退应用可保留新增表与审计，不能删除可能被后续配置引用的字典。需要API双租户/权限/并发/失败回滚及浏览器重开证据；部署备份恢复和全产品最终验收另行执行。
