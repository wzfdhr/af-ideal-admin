# 全产品组织管理第一条真实路径

对应 FP-002/003，承接全产品 Goal；R1 原包和分支保留。已实现部门树、父级编辑、岗位及成员组织绑定的真实纵向路径。模块部署/备份/回退与完整系统管理门禁仍须继续，不能由单条路径推出全产品完成。

## 复用与职责

现有 departmentSystem 页面复用 ProForm、ProTable、权限按钮和 request-client。共享 contracts 定义 Department、输入校验、DEPARTMENT_PERMISSIONS；参考 API organization 模块负责真实资源查询和命令；003_organization.sql 建部门表及组合租户关联。没有替换组件库或引入通用无语义 JSON CRUD。

GET /system/departments 为当前租户列表、分页、名称和状态过滤；GET /system/departments/:id 为授权详情。POST、PUT、DELETE 均需 Idempotency-Key；PUT 和 DELETE 需 expectedRevision。成功沿用 code 20000 与 traceId。未知字段422、无功能权限403、不可见资源404、版本/状态/幂等/引用冲突409。父部门可缺省/为null，写入不能引用其他租户、停用或删除的父部门；移动不能形成环。

写事务复用已授权成员刷新、幂等和事实审计；按租户组织树 advisory lock 串行树修改，再锁资源版本。成功事实审计同事务提交，重放不产生第二份。删除用墓碑保留资源历史，但有关联成员或活动子部门时拒绝，不以级联删除抹掉人员或业务数据。

## 兼容与初始化

003 增 departments 和 memberships.department_id；现有成员按旧部门名称建立确定性 legacy-dept 标识。004 增 positions、memberships.position_id 和租户/部门/岗位组合 FK；岗位必须属于成员绑定的同一部门。旧字段保留，当前名称从实时部门读取，已创建请假记录的 department_snapshot 保持不变。旧快照测试先实际创建一份请假记录，再修改组织绑定，避免空数据让断言虚假通过。

旧 Mock DTO 可无 revision，API helper 保留无新增参数调用；真实更新与删除必须带服务端返回版本。页面把编辑版本放在独立 ref 中，避免 ProForm 提交只保留 schema 字段时丢失版本；失败保留编辑内容。R1 参考服务没有 system 路由的历史版本不兼容新版页面，需要先执行迁移并更新 API。

platform-demo.js 仅允许 APP_MODE=demo 和专属 *_demo 数据库，显式初始化共享合成身份、真实部门及管理员的部门/岗位/组织绑定权限；不自动运行，不修改现有 R1 凭据或生产库。没有将应用配置管理员隐式升级为全站通配管理员。生产授权和最后管理员保护仍在 FP-004/005。

## 树、岗位与成员绑定

GET /system/departments/tree 返回当前租户的完整组织树。共享领域函数拒绝重复 ID、缺失父级和循环；按 sort/id 排序。页面允许展开/折叠，父级选项排除自身及整个子树；停用上级的所有后代选项不可用于新增绑定。每次打开编辑器重新读取选项，失败显示错误并保留输入。

GET /system/positions 支持分页和 departmentId 过滤。POST/PUT/DELETE 延续幂等键、版本与事务审计；重复岗位名、过期版本、已绑定成员的移动/删除均拒绝。GET /system/organization-members 只投影成员姓名、组织标识、岗位名称、版本和状态，未包含电话、邮箱、密码或授权配置。POST /system/organization-members/:id/assign 必须指定合法部门、该部门的启用岗位或 null，并提供成员版本。跨租户目标404，不匹配岗位422，停用部门或任何停用上级409。停用组织不删除既有人员身份/历史，新的绑定被拒绝；成员停用是独立 FP-004。

组织绑定权限包含读取部门/岗位目录的必要能力，不包含部门详情、组织写入或其他成员隐私。岗位列表权限也可读取部门目录以显示名称。客户端与服务端菜单采用任一岗位列表/绑定权限，写按钮仍逐项授权。岗位选择读取所有分页，变更部门后丢弃旧请求结果，避免只展示前100条或把旧部门岗位错用到新部门。

锁顺序固定为租户行 → 当前身份刷新 → 目标资源。普通 R1 命令取得租户共享锁，岗位/成员组织写入取得租户排他锁，部门树写入再取得树 advisory lock。两名管理员互相绑定的真实并发测试证明不会在当前身份共享锁和目标成员排他锁之间互相等待。排他锁会限制本租户组织写吞吐；容量目标尚未实测，不能宣传高并发数值。

新增 OrganizationDemoStore 只供显式开发 Mock 模式；共享严格输入契约、树规则、版本、引用和幂等检查，内存状态按租户隔离。真实接口失败不会进入它。Mock 页面浏览器证据与真实数据库/E2E分别归档；Mock 内存不会在整页刷新或进程重启后持久化，不能拿它证明真实保存/恢复或事实审计。

固定部门状态 /sys/dic/departmentStatus 返回受控枚举，非完整持久化字典模块；FP-008 仍未完成。其他系统页仍不可因新增一个入口宣称真实接入。
