# 条件流程真实执行方案

FP-013进行中，当前增量尚非正式完整模块交付。接续表单v1/v2、不可变组合发布和共同业务执行引擎，保留工作流v1串行语义。v2增加受控条件定义及两条明确出边；不引入用户脚本、任意表达式或远端调用，也不把并行节点冒充条件分支。

## 条件及字段边界

- 条件使用闭合JSON AST：all/any组合有界谓词，谓词声明表单字段、类型、固定运算符和值。文本/单选仅相等和不等，整数/金额/按日日期可比较先后；金额规范化为安全整数分位比较，不靠浮点阈值或JS表达式。
- 发布时针对同批表单快照验证字段确实存在、类型一致、字面值有界；数量×单价的已登记计算结果可作为明确声明的金额字段。拒绝未知引用、脚本、未来格式和多余属性。
- 条件读取提交后固定的业务字段与服务端计算值。未填可选字段的谓词为false，不从当前草稿、浏览器、其他租户或变更后的字典猜值。true选择matched出边，false选择fallback出边，字段不合法则事务失败。

## 图及推进语义

- 恰有一个开始和结束，审批仍每节点一名处理人；每个条件必须有准确两条不同分支，非条件节点至多一条出边。每个节点可达且到达结束，拒绝循环、悬空连线、重复边、无终点和未知分支。
- 两个互斥条件路径可以汇合到普通节点，但一个实例每次只沿选中路径推进。所有可执行完整路径必须至少有一个审批节点，禁止配置条件绕过审批。
- 先走条件/抄送直到下一个审批或结束；表单、流程定义与分支历史均固定于实例引用的release。两级既有串行审批保持原路径。拒绝并行/会签节点，FP-014另按其独立并发语义实现，不删除任务。
- 申请提交、审批后的继续推进都接入同一条件执行函数，并传真实固定字段。不会仅在预览模拟路由。流程版本切换与新发布不重写正在运行的实例。

## 事务、历史及恢复

- 条件选路由服务端产生事实事件，记录节点与matched/fallback结果，避免在日志、审计或通知中记录敏感操作数原文。若使用history action=route，增加新迁移扩展现有CHECK，不改已应用001至015校验和。
- 分支事件、实例位置、审批任务、业务状态、抄送outbox与审计保持同一事务，故障不留下半条路径。现有幂等receipt和记录/实例锁继续保证重复提交/并发处理只有一次效果。
- 下一处理人停用或撤权继续明确拒绝并保留当前状态，可恢复后重试或由申请人撤回；不会绕过该审批，也不在此阶段虚构转交/超时能力。进程重启读取数据库实例与原release继续推进。

## 设计器与发布接入

- 受控条件编辑器提供字段、类型、运算符、值、all/any组合及两条分支标识；reference模式不展示任意表达式输入。应用配置传当前关联表单定义，未保存的引用明确状态，发布针对实际保存revision验证。
- 发布校验、包导入导出依赖、客户端格式迁移和Mock兼容均识别workflow v1/v2。未来v3拒绝。旧v1含condition/parallel仍按旧串行门禁拒绝；不通过更改格式标签绕过校验。
- UI展示节点路由事实和错误恢复，权限继续检查当前用户、租户和业务对象。包重绑保留结构化条件及字段引用，清除源人员ID，并实际验证目标租户路径。

## 验收与交付

- 领域：金额精确边界/日期、all/any及缺值、两路与汇合、排序独立、循环/悬空/缺默认分支/无审批路径/错类型/脚本拒绝。
- API/真实数据库：发布后按数量/金额选不同审批人，后续条件与抄送、撤回、拒绝、下一处理人失效、错误恢复、故障回滚、幂等/并发、双租户拒绝、实例固定与进程替换。
- 真实浏览器：编辑保存重开、发布、两个实际业务分支、各处理人待办/详情、状态和路由历史、错误输入保留、版本切换后旧实例原路径、键盘及1280/1440；无成功响应注入。
- 必须跑现有完整门禁及对应提交的远端CI并归档。新迁移仅先用于专属开发demo，R1原部署/卷不改写；全新部署、备份恢复、兼容回退及正式目标验收仍需全产品交付阶段完成。

本增量实际格式：mode=all/any，predicates为1至10项扁平有界谓词；每条谓词field/valueType/operator/value，运算符eq/neq/gt/gte/lt/lte。edge.branch准确matched/fallback，不使用显示label猜分支。发布验证全部潜在处理人；提交用固定值先计算选中路径，只验证该路径的人员与自审。推进再复核实际下一处理人，防止运行中的停用/撤权。错误规则作为未保存编辑保留并由真实保存拒绝，不以沿用旧值伪造保存成功。

迁移016仅增加history route CHECK允许值，无既有数据重写；版本回退需保留016允许已写route的事实，旧二进制不支持workflow v2时不能读取或执行该定义，不能伪称直接降级格式。当前仍需全新部署/恢复/兼容回退的完整交付证据。
