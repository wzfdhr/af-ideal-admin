# 全产品身份与授权实施约束

对应 FP-004/005，2026-10-01，实施者 Codex。本文定义下一条真实路径，尚不是实现或部署完成证据。

## 用户与成员边界

users 是跨租户登录身份，memberships 是租户内资料和授权。租户管理员不能因为能编辑本租户成员就修改另一个租户共用身份的姓名、密码或全局状态。新增迁移保留原字段/历史，增加租户内显示姓名、电话、邮箱、时间和删除墓碑；身份创建来源使用可为空的租户关联，旧私有初始化和合成身份不自动归某个租户所有。

用户创建真实建立身份、私有密码哈希和本租户成员；用户名全局唯一，但冲突只返回通用可用性错误，不暴露其他租户身份信息。用户名不在后续普通资料编辑中改写。创建默认最小业务成员权限，角色和权限变更通过独立授权命令实施，不能把管理员传入的角色展示字符串等同于真实授权。

资料更新只改当前租户的成员字段，版本与组织绑定共用成员 revision。部门/岗位沿 FP-003 的受控绑定路径；旧界面的自由部门名称不能成为真实关联。账号列表和详情由服务端投影及脱敏，客户端不能通过隐藏列来承担字段授权。错误、审计和日志不记录密码、哈希或完整联系资料。

成员停用和撤销在当前租户即时生效，其他租户的合法成员不受影响；删除为停用的墓碑，不物理删除历史申请、审批、审计或会话关联。复用用户身份只能通过明确的授权邀请/绑定流程，不能靠客户端提交其他租户用户ID实现。先交付最小新身份创建/本租户资料维护和停用路径，再补授权角色。

当前有效的待办审批人不能被静默删除，必须先明确处理其待办或返回可操作冲突。最后一个有效管理者不能自行或被另一条并发命令停用/撤权；在租户排他锁内重新计算，不能靠先查询再无锁写入。治理能力根据真实权限集合判断，兼容 role 字段只用于旧界面展示。

## 私有凭据与会话

初始密码由私有输入传入，强校验并仅存现有密码哈希。响应、幂等重放、报告和审计不返回密码。管理员重置密码只能作用于本租户创建且未被其他租户共用的身份；共享或外部管理身份使用本人修改密码路径，不能被一个租户的管理员锁掉所有租户访问。

本人修改密码要求旧凭据验证、新密码校验，成功后撤销该身份旧会话，重新登录。授权和成员状态始终在后端重鉴权，不能用前端菜单刷新代替撤权。会话/资料/授权修改与成功审计同事务提交，命令版本和幂等必须同时成立。

登录防刷保留原账户/IP阈值。429 返回准确 Retry-After；登录页上的401不能通过再次跳转清空用户刚输入的凭据。诊断上传失败不阻断登录纠正。该问题已建立真实页面回归，最终结果须归档。

## 角色和权限

角色为 tenant+id 持久化资源，权限码从服务端受控目录选择。成员角色关联与角色权限绑定使用租户组合FK和版本，权限集合从有效角色及受控直接授权实时合并；停用角色、删除关联和权限变更必须影响下一次查询、命令、菜单和异步收件授权。

授权人不能授予自己没有的能力；新的治理权限不能因创建角色或填写名称自动出现。成员的 role=admin 或 role=user 不作为越权捷径，通配权限只沿原私有初始化约束允许。生产初始化与专用演示初始化分开，不向旧演示或生产成员自动授全站通配权限。

锁顺序沿租户 → 当前身份 → 目标成员/角色，治理命令使用租户排他锁，避免多管理员交叉更新及最后管理者并发检查竞态。异步通知/调度执行时继续重鉴权，不能缓存撤销前的角色权限集合作为最终授权依据。

## 已实施的首批后端与当前限制

005迁移已增加成员显示姓名、联系资料、墓碑、会话epoch及session_scopes，不改全局身份姓名。有效旧会话仅按迁移时原已授权的启用成员建立范围；新登录记录当前epoch，停用/删除推进epoch，再启用后旧租户会话仍拒绝，其他租户的范围不变。写事务刷新同时核对epoch，不能仅在请求开始校验。此迁移尚未纳入正式部署/回退验收。

真实system/users列表/详情/创建/部分资料修改/删除及reset-password已有API、版本、幂等和成功审计。列表/详情默认掩码，只有system:user:read-contacts可读联系资料原值，缺该能力不能用电话过滤推测数据。创建只给兼容user展示身份和空直接权限集合，未自动授予审批/配置能力。密码重置只允许本租户创建且没有其他租户成员的身份，并撤销旧会话；共享或外部管理身份拒绝。

当前最后管理员保护基于有效身份、有效成员和create/update/delete三项直接治理权限，在租户排他锁内计算。FP-005还必须将动态角色产生的有效权限纳入同一规则；不能宣称已完成动态角色治理。待处理的真实运行审批阻止停用/删除，转交功能仍由FP-015完成。旧状态、别名和历史记录保留，不物理删除身份。

后端当前54项数据库/HTTP回归通过，含7项用户与范围测试。用户页面、本人修改密码、完整角色/权限、独立Mock、多账号浏览器、部署/备份/回退和新CI仍未完成，因此FP-004/005保持未交付状态。后端测试不能代替用户实际操作路径。

## 实施与验收任务

1. 建失败回归：真实用户路由404、错误密码输入保留、跨租户成员资料/凭据不能修改。
2. 扩展严格共享契约、非破坏迁移、状态/字段投影及受控权限目录；保留旧初始化/登录/审批兼容。
3. 实现新身份创建、本租户资料维护、版本/幂等、停用/撤销、待办引用和最后管理员保护。
4. 实现私有密码设置/本人修改/受限管理员重置、会话失效及审计；不把哈希或私有输入写入证据。
5. 接入现有 ProForm/ProTable 页面，删除自由组织关联，明确角色授权未就绪时的边界；错误保留输入，敏感字段不会由掩码值覆盖原资料。
6. 实现角色CRUD、成员角色关联、受控权限绑定、即时撤权和并发保护；前后端权限保持一致。
7. 独立Mock场景、契约/领域、真实数据库/双租户/多账号页面/非法输入/并发/幂等/服务重启验收，回归R1与FP-002/003。
8. 补模块部署、增量迁移、完整备份、兼容回退及实际远端CI；只在完整证据具备后完成FP-004/005。

回滚先停止新身份/授权写入，按报告备份恢复或回退兼容代码；不删除身份、成员或角色历史。不兼容旧鉴权的授权迁移必须单独验证，不能在回退时让旧代码忽略有效撤权。
